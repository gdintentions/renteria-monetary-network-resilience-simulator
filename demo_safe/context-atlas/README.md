# Demo-Safe Context Atlas

A synthetic, in-memory knowledge-map demonstration.

The private project includes local persistence, browser UI, import/export, and additional controls. This public version exposes only the explainable graph idea.

## Demonstrates

- explicit Markdown-style wikilinks
- broken-link visibility
- lexical relationship suggestions
- no personal notes or private vault data

Run:

```bash
python demo.py
python demo.py --self-test
```
