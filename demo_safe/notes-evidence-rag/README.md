# Demo-Safe Notes Evidence RAG

A synthetic source-first Q&A miniature.

This public demo contains no personal notes, private document corpus, Ollama integration, or private retrieval implementation.

## Demonstrates

- lexical passage retrieval
- line-level evidence
- source identifiers and content hashes
- abstention when evidence is absent
- generated-draft citation-ID validation

The "generated draft" path uses a supplied string, not an external model.

Run:

```bash
python demo.py
python demo.py --self-test
```
