# Demo-Safe Polyglot Relay

A synthetic control-plane demonstration for governed multilingual interaction.

This public version does **not** include unrestricted translation, private provider adapters, browser voice code, or production integrations.

## Demonstrates

- supported sample phrases
- explicit unsupported-language behavior
- simple quality/risk routing
- human-review escalation for high-risk terms

Run:

```bash
python demo.py
python demo.py --self-test
```
