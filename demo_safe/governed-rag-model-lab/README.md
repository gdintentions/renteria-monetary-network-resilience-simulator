# Demo-Safe Governed RAG Model Lab

A synthetic evaluation miniature showing how retrieval approaches can be compared without exposing the private recruiter-lab repository.

## Demonstrates

- lexical Jaccard retrieval
- character-trigram Dice retrieval
- a transparent hybrid score
- small benchmark evaluation
- explicit warning that toy-fixture results do not generalize

Run:

```bash
python demo.py
python demo.py --self-test
```
