# Demo-Safe Personal Assistant Ledger

A synthetic, in-memory demonstration of the private project's memory and task-state controls.

This public demo contains no personal memory, SQLite database, real reminders, external messaging, connected accounts, or delivery integrations.

## Demonstrates

- editable memory state
- reminder vs external-action draft states
- explicit approval/cancellation
- terminal-state protection
- audit entries that record actions without memory values

Run:

```bash
python demo.py
python demo.py --self-test
```
