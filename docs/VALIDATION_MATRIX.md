## Why these evaluations are deliberately different

The four projects solve different problems, so a single score would be misleading.

- Governed RAG is evaluated as **information retrieval** on held-out relevance judgments.
- The monetary simulator is evaluated through **sensitivity** and a narrowly defined historical proxy replay.
- ArgusLoop is evaluated first as a **control/safety state machine** in a disposable environment.
- EvidenceWeave is evaluated as **structured conflict surfacing** on externally labeled conflict cases.

The portfolio avoids turning these unlike measurements into an overall “AI score.”

## Failure-first engineering rule

When a benchmark exposes a weakness:

1. preserve the original labels and evaluation definition;
2. publish the failure IDs or categories;
3. change the model/system rather than moving the goalposts;
4. rerun the same evaluation;
5. compare the before/after metrics;
6. keep the boundary between synthetic, controlled, external, and production evidence explicit.

That process is now part of the portfolio's engineering standard.
