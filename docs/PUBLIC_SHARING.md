## Required project introduction fields

State the problem, intended user and implemented behavior. Include a three-step walkthrough, exact release/test evidence, one observed failure, the limits of the evaluation, the next gap and the author's contribution (including AI assistance). Provide a screenshot and public evidence link. Use measured results only for the evaluated component. Avoid general accuracy, production readiness, live translation, autonomous delivery or forecasting claims unless that specific behavior is implemented and validated.
