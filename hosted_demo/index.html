What is real

Working browser interactions, deterministic client-side logic, synthetic fixtures, visible controls, and explicit failure/abstention states.

What stays private

Private repository source, proprietary implementation details, credentials, real user data, provider integrations, richer prompts, and sensitive configuration.

What is not claimed

Production readiness, market demand, calibrated probabilities, real-world translation quality, or forecasting skill.

What green tests mean

Only that tested code paths passed for that revision. They are not proof of external effectiveness or complete security.
